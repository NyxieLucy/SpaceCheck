# SpaceCheck

SpaceCheck is a fast, intuitive storage and disk space analyzer built to help you track down large files, visualize folder usage, and reclaim precious disk space effortlessly.

---

## Features

- Fast Directory Scanning: Rapidly indexes your filesystem or targeted directories.
- Visual Usage Breakdown: Displays disk consumption with easy-to-read hierarchies and progress bars.
- Top Space Hog Detection: Instantly identifies the largest directories and files cluttering your drive.
- Lightweight & Efficient: Designed for minimal CPU and memory footprint during scans.
